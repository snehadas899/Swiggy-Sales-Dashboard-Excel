# Swiggy-Sales-Dashboard-Excel

## Project Overview
This project is an interactive Excel dashboard built using Swiggy sales data. It provides insights into sales performance, customer ratings, restaurant performance, and regional sales using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

## Tools Used
- Microsoft Excel

## Features
- Interactive Slicers
  - Month
  - Food Type
  - State
  - Category

- KPI Cards
  - Total Sales
  - Total Orders
  - Average Order Value
  - Average Rating
  - Rating Count

- Visualizations
  - Monthly Sales Trend
  - Daily Sales Trend
  - Regional Sales Map
  - Top 10 Restaurants
  - Top 5 Cities
  - Sales by Food Type
  - Quarter-wise Sales, Average Rating & Orders
